# Scoop Haven Ecommerce Website

A premium, mobile-friendly ice cream storefront with:

- responsive landing page
- product catalog with filters and search
- shopping cart drawer
- checkout modal form
- newsletter signup and customer review sections

## How to run

Open `index.html` directly in a browser, or serve locally with:

```bash
python -m http.server 8000
```

Then visit:

http://localhost:8000

## Files

- `index.html` — page structure
- `styles.css` — full visual design and responsive layout
- `script.js` — product rendering, cart logic, filters, checkout flow

## Notes

This is a front-end storefront demo and uses simulated cart/checkout behavior without a backend.
